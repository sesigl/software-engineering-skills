# Quiz

Recalling an answer strengthens memory more than reading it again, and a slightly hard question teaches more than an easy one.

Agree on the number of questions, then ask one per message and wait for each answer. Cover all levels and every part of the map. Favour questions that need understanding (apply it to a new scenario, predict what happens if a part is removed, spot the mistake in a wrong explanation, compare with an alternative) over recalling details. Use new scenarios, not the running example.

For multiple choice, keep options alike in length and style so the format gives nothing away, and build wrong options from real misconceptions, including the learner's own. Mix in open questions now and then, so the learner has to produce an answer.

After each answer, say whether it is right and why. If they chose a wrong option, explain why it was tempting; a clear correction after an error is one of the best moments for learning. If the same gap shows up twice, pause and re-explain it briefly.

At the end, give the score kindly, name what they know well and the one part worth reviewing, and suggest repeating a few questions in a few days.
